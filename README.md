# Hotel-Reservation-Operations-Analytics
Clean data (dates, duplicates, statuses) and build a Star Schema (Fact_Bookings, Fact_Operations; Dim_Date, Property, Room, Guest, Staff). Track Occupancy %, ADR, RevPAR, Cancellation %, and Turnaround Time via DAX. Build dashboards for Revenue, Guest Behaviour, and Staff Utilization to fix bottlenecks, cut cancellations, and optimize room mix.
